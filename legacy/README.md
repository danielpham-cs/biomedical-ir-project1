# Legacy Homework 2 material

Kept for reference only; nothing here is imported by the app, scripts or tests.

- `hw2_diabetes/`: first Homework 2 version on 100 diabetes abstracts. It includes `src/homework2.py`, `scripts/run_homework2.py`, its old tests, `output/homework2/`, the old page `5_Homework_2.py` and planning documents. Its modules import `src.homework2`; to run them, copy `src/homework2.py` back into `src/`.
- `project2_single_page/`: the seven-screen single-page Project 2 workspace (`project2_workspace.py`) and its implementation notes. It was replaced by the six pages under `pages/1x_HW2_*.py` and `ui/hw2/`.

The current system description is `docs/HW2.md`.
